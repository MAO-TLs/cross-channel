Installation

How to install the patch

Requires a legally obtained, unmodified Japanese CROSS†CHANNEL ～FINAL COMPLETE～ 1.0 installation and Python 3. The installer checks compatibility before changing any game files.

  1. 01

    Close the game and extract the patch

    Download and extract the complete patch ZIP. Keep install_patch.py, manifest.json, and the patches folder together.

  2. 02

    Install the English patch

    Open a terminal in the extracted patch folder. On Windows, run py -3 install_patch.py install "C:\Games\CROSS CHANNEL", replacing the quoted path with your game folder. On macOS or Linux, use python3 instead of py -3.

  3. 03

    Launch the game

    Launch cc.exe normally, or through Wine on macOS or Linux. Original-file backups are retained, and the installer does not replace your saves.

  4. 04

    Restore the originals if needed

    Run the installation command with restore instead of install. Keep the original-file backup folder for restoration. The included README explains compatibility checks and recovery.
