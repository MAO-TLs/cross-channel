## Supported release

- *CROSS†CHANNEL ～FINAL COMPLETE～* (2014 Windows edition)
- Japanese `data/sn.bin` SHA-256: `ab1c90cfd58e2f4be34edb75e8dcf41333474dc228cd1a19103387317fcf9d9f`

The patch contains no executable, art, music, voices, movies, disc image, or
other game files. It replaces only `data/sn.bin` in a legally obtained copy.

## Requirements

- A legally obtained Japanese copy of *CROSS†CHANNEL ～FINAL COMPLETE～*
- Python 3.10 or newer

The included helpers install, verify, and restore the patch on Windows or
through Wine on macOS/Linux. The installer verifies the exact Japanese source
hash, keeps a verified Japanese backup, and never launches the game.

## Public edition

The site publishes 50,942 Japanese and MAO English rows across 322 readable
scripts. The engine patch projects the finalized translation across all 353
scenario scripts and 472 script-layer choices.

George Henry Shaft's English is displayed only where a defensible alignment
exists. Its separate source audit records 6,899 confirmed findings across
38,637 comparable units. The complete *On Cross Channel* monograph is also
published in its original chapter and paragraph structure with 847 recorded
annotations.

George Henry Shaft's translation was not used to create or revise the MAO
English translation.
