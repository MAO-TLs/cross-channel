## English patch

Download [v1.1.3](https://github.com/MAO-TLs/cross-channel/releases/tag/v1.1.3) and follow the included README. It requires an unmodified Final Complete 1.0 installation and Python 3. This release restores 3,374 translated lines across 11 scripts and retains the branch and entry-point repairs associated with issues #5–#7.

The rebuilt archive passed source-binding, decode, instruction-shape, entry-target, and unaffected-payload checks. The v1.1.2 control-flow repair separately exercised all 1,135 corrected branches using the shipped game's machine code in an x86 emulator. Actual scene replay and a full playthrough remain unverified. See [v1.1.3 validation](maintenance/v1.1.3/).

Allow at least 5 GB free disk space and 8 GB RAM. If upgrading, restore the original game with your previous patch installer before installing this package; keep the old installer and backup until restoration succeeds. Save data is untouched. The [v1.1.3 manuscript](https://github.com/MAO-TLs/cross-channel/releases/download/v1.1.3/CROSS-CHANNEL-English-Script-v1.1.3.jsonl) matches the online script.
